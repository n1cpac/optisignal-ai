OPTISIGNAL-AI - COMO EJECUTAR EL BACKEND Y EL PANEL
===================================================

Se necesitan DOS terminales de PowerShell abiertas al mismo tiempo: una para el backend
y otra para el panel. No cierres ninguna mientras uses el sistema.


REQUISITOS (solo la primera vez)
--------------------------------
- Python 3.12 (o 3.11) con las dependencias de backend/requirements.txt instaladas.
- Node.js y npm (comprobar con: node --version).
- Videos de validacion reales en data/test_videos/cctv_s1.mp4 ... cctv_s8.mp4.
- Pesos del detector unificado en models/optisignal_best.pt.


1. BACKEND  (terminal 1)
------------------------
Desde la raiz del repositorio (optisignal-ai):

Solo si creas un entorno virtual por primera vez:
  python -m venv backend\.venv
  backend\.venv\Scripts\pip install -r backend\requirements.txt

Para ejecutar el backend:
  $env:PYTHONPATH="backend"
  python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --timeout-graceful-shutdown 2

(Si usas el entorno virtual del backend, reemplaza `python` por `backend\.venv\Scripts\python`.)

Listo cuando aparece:  Uvicorn running on http://0.0.0.0:8000
La API REST responde en http://localhost:8000 (Swagger UI en http://localhost:8000/docs).


2. PANEL WEB ANGULAR  (terminal 2)
----------------------------------
cd "frontend\Semaforos 3\panel-supervision-semaforo"

Solo la primera vez:
  npm install

Cada vez:
  npm start

Listo cuando aparece:  Local: http://localhost:4200/


3. ABRIR Y USAR EL PANEL
------------------------
En el navegador:  http://localhost:4200

- El mapa carga las 8 intersecciones activas de Bogota D.C. (s1 a s8), reproduciendo en
  bucle a 15 FPS los videos de data/test_videos/cctv_s1.mp4 a cctv_s8.mp4.
- Al seleccionar un semaforo se visualiza el stream MJPEG en tiempo real con las cajas
  estabilizadas y numeradas de izquierda a derecha (#1, #2, #3...).
- El panel izquierdo muestra las alertas activas simplificadas (zona, fecha/hora y alerta).
- Al enviar un reporte desde el detalle de una interseccion puedes indicar si hubo falla,
  elegir tipo de falla ("funcionamiento" o "dano") y seleccionar los numeros de cabezales
  afectados (#1..#N). La alerta reportada sale de la vista "Actuales" y pasa a "Historial"
  junto con su imagen de escena correspondiente (data/history_scenes/escena_s1..s8.png).
- En la esquina inferior izquierda hay un boton discreto de reinicio de base de datos que
  llama a POST /reportes/reset para limpiar reportes y re-evaluar las alertas vivas.


4. DETENER
----------
Ctrl+C en cada terminal. Si uvicorn tarda en cerrar, pulsa Ctrl+C otra vez.


CONFIGURACION  (archivo CONFIG_PARAMETERS.yaml, en la raiz del proyecto)
------------------------------------------------------------------------
Reinicia el backend despues de cualquier cambio en este archivo.

- Modelo detector: configurado en detector > model_path (por defecto models/optisignal_best.pt,
  input_size: 1280, ensemble: false).
- Tracking y estabilizacion: se ajustan bajo detector > tracker (type: bytetrack,
  kalman_process_noise, kalman_measurement_noise, temporal_window_seconds: 5.5, etc.).
- FPS de reproduccion y captura: camera > fps (por defecto 15 FPS).
- Agregar o reubicar un semaforo: indica id, nombre en formato "via con via" (por ejemplo
  "AK 68 con CL 26") y source (ruta a video o indice de camara). Si la interseccion no tiene
  lat/lng manuales, el backend la ubica automaticamente usando la Malla Vial de Bogota.


PRUEBAS AUTOMATICAS  (con el backend detenido)
----------------------------------------------
Desde la raiz del repositorio:
  $env:PYTHONPATH="backend"
  pytest backend/tests -v

Cobertura actual: 83 pruebas (API, base de datos, clasificador HSV, FSM, georreferenciacion
y casos reales de las 8 camaras de Bogota s1-s8).


PROBLEMAS COMUNES
-----------------
- El mapa no muestra puntos: verifica que el backend este ejecutandose en el puerto 8000.
- Videos no encontrados al arrancar: verifica que existan data/test_videos/cctv_s1.mp4 a s8.mp4
  y el modelo models/optisignal_best.pt.
- El historial no muestra imagen de escena: verifica la carpeta data/history_scenes/.
- Puerto ocupado (8000 o 4200): cierra la instancia previa antes de iniciar nuevamente.
